# Australian city saves

Download a playable `.save`, open Trainsworld and choose **Load file**. This index tracks the current save for each city on the `australian-city-maps` branch. The save filenames stay the same as the networks are updated.

| Perth | [Perth](saves/perth.save) | | [Perth Station and Bayswater approaches](PERTH_APPROACH.md) |

The blueprint files keep the track, platforms and transfers with a construction budget and no services. You can edit the geometry in the game and export a new `.save`.

Earlier Melbourne and Sydney builds live in [archive/](archive/) for comparison and reproduction. The city reports document data sources, assumptions, validation and build commands. Game code and its run instructions remain in the [repository root](../README.md).
